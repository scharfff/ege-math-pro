# Задание 10. Движение по воде (течение реки)

**Справочник:** формулы и методы решения для ЕГЭ по математике (профильный уровень)

**Код КИМ:** 2.1  
**Баллы:** 1  
**Время:** 2 мин

**Что нужно уметь:** решать задачи на движение по воде (по течению, против течения, туда и обратно).

---

## 1. Основные формулы движения

| Величина | Формула | Связь |
|:---|:---|:---|
| Путь | $$S = v \cdot t$$ | |
| Скорость | $$v = \frac{S}{t}$$ | |
| Время | $$t = \frac{S}{v}$$ | |

---

## 2. Движение по воде

**Собственная скорость** — скорость в неподвижной воде: $$v_{соб}$$  
**Скорость течения:** $$v_{теч}$$  
**Путь (расстояние):** $$S$$

### 2.1. Скорость по воде

| Ситуация | Скорость по воде | Формула времени |
|:---|:---|:---|
| По течению | $$v_{по} = v_{соб} + v_{теч}$$ | $$t_{по} = \frac{S}{v_{соб} + v_{теч}}$$ |
| Против течения | $$v_{пр} = v_{соб} - v_{теч}$$ | $$t_{пр} = \frac{S}{v_{соб} - v_{теч}}$$ |

### 2.2. Полезные соотношения

$$v_{соб} = \frac{v_{по} + v_{пр}}{2}, \quad v_{теч} = \frac{v_{по} - v_{пр}}{2}$$

### 2.3. Туда и обратно (одинаковый путь $$S$$)

$$t = t_{по} + t_{пр} = \frac{S}{v_{соб} + v_{теч}} + \frac{S}{v_{соб} - v_{теч}}$$

$$t = \frac{2 S \cdot v_{соб}}{v_{соб}^2 - v_{теч}^2}$$

---

## 3. Методы решения

### 3.1. Введение неизвестных и составление уравнения

1. Выбрать неизвестное (собственная скорость, скорость течения, время).
2. Выразить остальные величины через него из условия.
3. Использовать ключевую связь из условия (равенство путей, времени) и получить уравнение.
4. Решить уравнение, проверить по смыслу (положительность, $$v_{соб} > v_{теч}$$).

### 3.2. Таблица для движения по воде

| Направление | $$v$$ | $$t$$ | $$S$$ |
|:---|:---|:---|:---|
| По течению | $$v_{соб} + v_{теч}$$ | … | … |
| Против течения | $$v_{соб} - v_{теч}$$ | … | … |

Заполнить строки по условию и связать столбцы формулой $$S = vt$$.

### 3.3. Проверка ответа

- Все ли величины положительны и подходят по смыслу.
- Собственная скорость должна быть больше скорости течения: $$v_{соб} > v_{теч}$$.
- Выполняются ли все условия задачи (время, путь).
- Ответ записать в требуемом виде (целое число или конечная десятичная дробь).

---

## 4. Пример использования формул

**Движение по воде.** Собственная скорость лодки $$v_{соб}$$, течения $$v_{теч}$$. Время по течению на путь $$S$$: $$t_1 = \frac{S}{v_{соб}+v_{теч}}$$; против: $$t_2 = \frac{S}{v_{соб}-v_{теч}}$$. Если дано $$t_1$$ и $$t_2$$, можно найти $$v_{соб}$$ или $$v_{теч}$$ из системы.
