## Прототип 1: Показательные неравенства

### Задача 1.1 (ФИПИ)

**Условие:** Решите неравенство $$2^{x+1} \geq 8$$.

**Решение:**

$$2^{x+1} \geq 2^3$$

Основание $$2 > 1$$, знак неравенства сохраняется:

$$x + 1 \geq 3$$

$$x \geq 2$$

**Ответ:** $$[2; +\infty)$$

---

### Задача 1.2 (ФИПИ)

**Условие:** Решите неравенство $$\left(\frac{1}{3}\right)^{x-2} < 9$$.

**Решение:**

$$\left(\frac{1}{3}\right)^{x-2} < 3^2$$

$$3^{-(x-2)} < 3^2$$

$$3^{2-x} < 3^2$$

Основание $$3 > 1$$, знак неравенства сохраняется:

$$2 - x < 2$$

$$-x < 0$$

$$x > 0$$

**Ответ:** $$(0; +\infty)$$

---

### Задача 1.3 (ФИПИ — квадратичная показательная)

**Условие:** Решите неравенство $$4^x - 5 \cdot 2^x + 4 \leq 0$$.

**Решение:**

Замена: $$t = 2^x$$, $$t > 0$$

$$t^2 - 5t + 4 \leq 0$$

$$(t - 1)(t - 4) \leq 0$$

$$1 \leq t \leq 4$$

Обратная замена:

$$1 \leq 2^x \leq 4$$

$$2^0 \leq 2^x \leq 2^2$$

$$0 \leq x \leq 2$$

**Ответ:** $$[0; 2]$$

---

## Прототип 2: Логарифмические неравенства

### Задача 2.1 (ФИПИ)

**Условие:** Решите неравенство $$\log_2 (x - 1) > 3$$.

**Решение:**

ОДЗ: $$x - 1 > 0 \Rightarrow x > 1$$

$$\log_2 (x - 1) > \log_2 8$$

Основание $$2 > 1$$, знак неравенства сохраняется:

$$x - 1 > 8$$

$$x > 9$$

С учётом ОДЗ: $$x > 9$$.

**Ответ:** $$(9; +\infty)$$

---

### Задача 2.2 (ФИПИ)

**Условие:** Решите неравенство $$\log_{0{,}5} (x + 2) \geq -1$$.

**Решение:**

ОДЗ: $$x + 2 > 0 \Rightarrow x > -2$$

$$\log_{0{,}5} (x + 2) \geq \log_{0{,}5} 2$$

Основание $$0{,}5 < 1$$, знак неравенства меняется:

$$x + 2 \leq 2$$

$$x \leq 0$$

С учётом ОДЗ: $$-2 < x \leq 0$$.

**Ответ:** $$(-2; 0]$$

---

### Задача 2.3 (ФИПИ — логарифм с переменным основанием)

**Условие:** Решите неравенство $$\log_x 8 < 3$$.

**Решение:**

ОДЗ: $$x > 0$$, $$x \neq 1$$

**Случай 1:** $$x > 1$$

$$\log_x 8 < 3 \Rightarrow 8 < x^3 \Rightarrow x > 2$$

С учётом $$x > 1$$: $$x > 2$$.

**Случай 2:** $$0 < x < 1$$

$$\log_x 8 < 3 \Rightarrow 8 > x^3 \Rightarrow x < 2$$

С учётом $$0 < x < 1$$: $$0 < x < 1$$.

**Ответ:** $$(0; 1) \cup (2; +\infty)$$

---

## Прототип 3: Рациональные неравенства (метод интервалов)

### Задача 3.1 (ФИПИ)

**Условие:** Решите неравенство $$\frac{x - 3}{x + 2} \geq 0$$.

**Решение:**

ОДЗ: $$x \neq -2$$

Находим нули числителя и знаменателя:

- Числитель: $$x - 3 = 0 \Rightarrow x = 3$$
- Знаменатель: $$x + 2 = 0 \Rightarrow x = -2$$

Отмечаем на числовой прямой: $$-2$$ (выколота), $$3$$ (закрашена, так как $$\geq$$).

Определяем знак на интервалах:

| Интервал | $$(-\infty; -2)$$ | $$(-2; 3)$$ | $$(3; +\infty)$$ |
|:---|:---:|:---:|:---:|
| Знак | $$+$$ | $$-$$ | $$+$$ |

Неравенство $$\geq 0$$, выбираем интервалы с $$+$$:

$$x \in (-\infty; -2) \cup [3; +\infty)$$

**Ответ:** $$(-\infty; -2) \cup [3; +\infty)$$

---

### Задача 3.2 (ФИПИ)

**Условие:** Решите неравенство $$\frac{(x - 1)(x + 3)}{x - 2} < 0$$.

**Решение:**

ОДЗ: $$x \neq 2$$

Нули: $$x = 1$$, $$x = -3$$, $$x = 2$$ (выколота).

| Интервал | $$(-\infty; -3)$$ | $$(-3; 1)$$ | $$(1; 2)$$ | $$(2; +\infty)$$ |
|:---|:---:|:---:|:---:|:---:|
| Знак | $$-$$ | $$+$$ | $$-$$ | $$+$$ |

Неравенство $$< 0$$, выбираем интервалы с $$-$$:

$$x \in (-\infty; -3) \cup (1; 2)$$

**Ответ:** $$(-\infty; -3) \cup (1; 2)$$

---

## Прототип 4: Иррациональные неравенства

### Задача 4.1 (ФИПИ)

**Условие:** Решите неравенство $$\sqrt{x + 3} > 2$$.

**Решение:**

ОДЗ: $$x + 3 \geq 0 \Rightarrow x \geq -3$$

Возводим в квадрат (правая часть положительна):

$$x + 3 > 4$$

$$x > 1$$

С учётом ОДЗ: $$x > 1$$.

**Ответ:** $$(1; +\infty)$$

---

### Задача 4.2 (ФИПИ)

**Условие:** Решите неравенство $$\sqrt{x - 1} \leq x - 3$$.

**Решение:**

ОДЗ: $$x - 1 \geq 0 \Rightarrow x \geq 1$$ и $$x - 3 \geq 0 \Rightarrow x \geq 3$$

Итого ОДЗ: $$x \geq 3$$

Возводим в квадрат:

$$x - 1 \leq (x - 3)^2$$

$$x - 1 \leq x^2 - 6x + 9$$

$$x^2 - 7x + 10 \geq 0$$

$$(x - 2)(x - 5) \geq 0$$

$$x \leq 2$$ или $$x \geq 5$$

С учётом ОДЗ ($$x \geq 3$$): $$x \geq 5$$.

**Ответ:** $$[5; +\infty)$$

---

## Прототип 5: Комбинированные неравенства

### Задача 5.1 (ФИПИ — показательное + логарифмическое)

**Условие:** Решите систему неравенств:

$$\begin{cases} 2^x \geq 4 \\ \log_2 x \leq 3 \end{cases}$$

**Решение:**

Из первого неравенства:

$$2^x \geq 2^2 \Rightarrow x \geq 2$$

Из второго неравенства:

ОДЗ: $$x > 0$$

$$\log_2 x \leq \log_2 8 \Rightarrow x \leq 8$$

Пересечение: $$2 \leq x \leq 8$$.

**Ответ:** $$[2; 8]$$

---

### Задача 5.2 (ФИПИ — дробно-рациональное с модулем)

**Условие:** Решите неравенство $$\frac{|x - 2|}{x + 1} < 1$$.

**Решение:**

ОДЗ: $$x \neq -1$$

**Случай 1:** $$x \geq 2$$

$$\frac{x - 2}{x + 1} < 1$$

$$x - 2 < x + 1$$

$$-2 < 1$$ (верно всегда)

С учётом $$x \geq 2$$: $$x \geq 2$$.

**Случай 2:** $$x < 2$$

$$\frac{2 - x}{x + 1} < 1$$

$$2 - x < x + 1$$

$$1 < 2x$$

$$x > 0{,}5$$

С учётом $$x < 2$$ и $$x \neq -1$$: $$0{,}5 < x < 2$$.

Объединяем: $$x \in (0{,}5; 2) \cup [2; +\infty) = (0{,}5; +\infty)$$.

**Ответ:** $$(0{,}5; +\infty)$$

## Ловушки и частые ошибки

1. **Забывают проверить ОДЗ** (особенно в логарифмических и иррациональных неравенствах)
2. **При основании меньше 1 забывают менять знак неравенства**
3. **В методе интервалов неправильно определяют знак на интервалах**
4. **Забывают выколоть точки, где знаменатель равен нулю**
5. **При возведении в квадрат забывают проверить, что правая часть неотрицательна**
6. **В логарифмических неравенствах с переменным основанием забывают рассмотреть два случая** ($$a > 1$$ и $$0 < a < 1$$)
7. **Путают строгие и нестрогие неравенства** (забывают закрашивать/выкалывать точки)
8. **При замене переменной забывают вернуться к исходной переменной**
