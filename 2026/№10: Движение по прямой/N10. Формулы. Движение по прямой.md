# Задание 10. Движение по прямой

**Справочник:** формулы и методы решения для ЕГЭ по математике (профильный уровень)

**Код КИМ:** 2.1  
**Баллы:** 1  
**Время:** 2 мин

**Что нужно уметь:** решать задачи на движение по прямой (встречное движение, движение в одном направлении, удаление).

---

## 1. Основные формулы движения

| Величина | Формула             |
| :------- | :------------------ |
| Путь     | $$S = v \cdot t$$   |
| Скорость | $$v = \frac{S}{t}$$ |
| Время    | $$t = \frac{S}{v}$$ |

**Равномерное движение:** при постоянной скорости $$S$$ и $$t$$ пропорциональны.

---

## 2. Движение по прямой (два объекта)

### 2.1. Встречное движение

Тела движутся навстречу друг другу.

$$S = S_1 + S_2 = v_1 t + v_2 t = (v_1 + v_2) t$$

**Скорость сближения:** $$v_{сбл} = v_1 + v_2$$

### 2.2. Движение в одном направлении (вдогонку)

Один объект догоняет другого.

$$S_1 - S_2 = L \quad \Rightarrow \quad v_1 t - v_2 t = L$$

**Скорость сближения:** $$v_{сбл} = v_1 - v_2$$ (при $$v_1 > v_2$$)

### 2.3. Движение в противоположных направлениях

Тела удаляются друг от друга.

$$S = S_1 + S_2 = (v_1 + v_2) t$$

**Скорость удаления:** $$v_{уд} = v_1 + v_2$$

---

## 3. Движение по кругу

### 3.1. Два тела из одной точки в одном направлении

Время до первого обгона ($$v_1 > v_2$$, $$L$$ — длина круга):

$$t = \frac{L}{v_1 - v_2}$$

### 3.2. В противоположных направлениях

Время до первой встречи:

$$t = \frac{L}{v_1 + v_2}$$

### 3.3. Разница в $$n$$ кругов

Путь первого минус путь второго равен $$n \cdot L$$:

$$v_1 t - v_2 t = n \cdot L \quad \Rightarrow \quad t = \frac{n \cdot L}{v_1 - v_2}$$

---

## 4. Методы решения

### 4.1. Введение неизвестных и составление уравнения

1. Выбрать неизвестное (скорость, время, расстояние).
2. Выразить остальные величины через него из условия.
3. Использовать ключевую связь из условия (равенство путей, времени) и получить уравнение.
4. Решить уравнение, проверить по смыслу (положительность).

### 4.2. Таблица для движения

| Объект | $$v$$ | $$t$$ | $$S$$ |
|:---|:---|:---|:---|
| 1 | … | … | … |
| 2 | … | … | … |

Заполнить строки по условию и связать столбцы формулой $$S = vt$$.

### 4.3. Проверка ответа

- Все ли величины положительны и подходят по смыслу.
- Выполняются ли все условия задачи (время, путь).
- Ответ записать в требуемом виде (целое число или конечная десятичная дробь).
