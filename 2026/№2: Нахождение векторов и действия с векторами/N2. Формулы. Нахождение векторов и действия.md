# Задание 2. Формулы. Нахождение векторов и действия с векторами

**Формулы и ключевые идеи** для ЕГЭ по математике (профильный уровень)

**Баллы:** 1  
**Время:** 1 мин  

---

## 1. Основные понятия

**Вектор** - направленный отрезок, характеризующийся длиной и направлением.

**Обозначение:** $$\vec{a}$$$$\overrightarrow{AB}$$

**Координаты вектора:** $$\vec{a} = (a_x; a_y)$$ или $$\vec{a} = (a_x; a_y; a_z)$$ (в пространстве)

**Нулевой вектор:** $$\vec{0} = (0; 0)$$ или $$\vec{0} = (0; 0; 0)$$

**Равные векторы:** векторы с одинаковыми координатами

---

## 2. Координаты вектора по двум точкам

Если даны точки $$A(x_1; y_1)$$ и $$B(x_2; y_2)$$, то вектор $$\overrightarrow{AB}$$:

$$\overrightarrow{AB} = (x_2 - x_1; y_2 - y_1)$$

**В пространстве:** $$A(x_1; y_1; z_1)$$, $$B(x_2; y_2; z_2)$$

$$\overrightarrow{AB} = (x_2 - x_1; y_2 - y_1; z_2 - z_1)$$

---

## 3. Длина вектора (модуль)

**На плоскости:**

$$|\vec{a}| = \sqrt{a_x^2 + a_y^2}$$

**В пространстве:**

$$|\vec{a}| = \sqrt{a_x^2 + a_y^2 + a_z^2}$$

**Расстояние между двумя точками:**

$$AB = |\overrightarrow{AB}| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

**В пространстве:**

$$AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

---

## 4. Действия с векторами

### 4.1. Сложение векторов

**Правило треугольника:** $$\vec{a} + \vec{b} = \vec{c}$$

**Координатная форма:**

$$\vec{a} + \vec{b} = (a_x + b_x; a_y + b_y)$$

**В пространстве:**

$$\vec{a} + \vec{b} = (a_x + b_x; a_y + b_y; a_z + b_z)$$

### 4.2. Вычитание векторов

$$\vec{a} - \vec{b} = (a_x - b_x; a_y - b_y)$$

**В пространстве:**

$$\vec{a} - \vec{b} = (a_x - b_x; a_y - b_y; a_z - b_z)$$

### 4.3. Умножение вектора на число

$$k \vec{a} = (k a_x; k a_y)$$

**В пространстве:**

$$k \vec{a} = (k a_x; k a_y; k a_z)$$

**Свойства:**
- Если $$k > 0$$, направление не меняется
- Если $$k < 0$$, направление меняется на противоположное
- $$|k\vec{a}| = |k| \cdot |\vec{a}|$$

---

## 5. Условие коллинеарности векторов

Векторы $$\vec{a}$$ и $$\vec{b}$$ **коллинеарны**, если существует число $$k$$, такое что:

$$\vec{a} = k \vec{b}$$

**Через координаты:**

$$\frac{a_x}{b_x} = \frac{a_y}{b_y} = k$$

**В пространстве:**

$$\frac{a_x}{b_x} = \frac{a_y}{b_y} = \frac{a_z}{b_z} = k$$

---

## 6. Координаты середины отрезка

Если даны точки $$A(x_1; y_1)$$ и $$B(x_2; y_2)$$, то середина отрезка $$M$$:

$$M\left(\frac{x_1 + x_2}{2}; \frac{y_1 + y_2}{2}\right)$$

**В пространстве:**

$$M\left(\frac{x_1 + x_2}{2}; \frac{y_1 + y_2}{2}; \frac{z_1 + z_2}{2}\right)$$

---

## 7. Деление отрезка в данном отношении

Если точка $$M$$ делит отрезок $$AB$$ в отношении $$\lambda : \mu$$ (считая от $$A$$), то:

$$M\left(\frac{\mu x_1 + \lambda x_2}{\lambda + \mu}; \frac{\mu y_1 + \lambda y_2}{\lambda + \mu}\right)$$

**Частный случай (середина):** $$\lambda = \mu = 1$$
