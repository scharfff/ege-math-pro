## Прототип 1: Координаты вектора по двум точкам

### Задача 1.1 (ФИПИ)

**Условие:** Даны точки $$A(2; 3)$$ и $$B(5; 7)$$ Найдите координаты вектора $$\overrightarrow{AB}$$

**Решение:**

$$\overrightarrow{AB} = (x_B - x_A; y_B - y_A) = (5 - 2; 7 - 3) = (3; 4)$$

**Ответ:** $$(3; 4)$$

---

### Задача 1.2 (ФИПИ - в пространстве)

**Условие:** Даны точки $$A(1; 2; 3)$$ и $$B(4; 6; 8)$$ Найдите координату $$z$$ вектора $$\overrightarrow{AB}$$

**Решение:**

$$\overrightarrow{AB} = (4 - 1; 6 - 2; 8 - 3) = (3; 4; 5)$$

Координата $$z = 5$$

**Ответ:** $$5$$

---

## Прототип 2: Длина вектора

### Задача 2.1 (ФИПИ)

**Условие:** Найдите длину вектора $$\vec{a} = (6; 8)$$

**Решение:**

$$|\vec{a}| = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10$$

**Ответ:** $$10$$

---

### Задача 2.2 (ФИПИ - расстояние между точками)

**Условие:** Найдите расстояние между точками $$A(1; 2)$$ и $$B(4; 6)$$

**Решение:**

$$AB = \sqrt{(4 - 1)^2 + (6 - 2)^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

**Ответ:** $$5$$

---

### Задача 2.3 (ФИПИ - в пространстве)

**Условие:** Найдите длину вектора $$\vec{a} = (2; 3; 6)$$

**Решение:**

$$|\vec{a}| = \sqrt{2^2 + 3^2 + 6^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = 7$$

**Ответ:** $$7$$

---

## Прототип 3: Сложение и вычитание векторов

### Задача 3.1 (ФИПИ)

**Условие:** Даны векторы $$\vec{a} = (2; 3)$$ и $$\vec{b} = (4; 5)$$ Найдите координаты вектора $$\vec{c} = \vec{a} + \vec{b}$$

**Решение:**

$$\vec{c} = (2 + 4; 3 + 5) = (6; 8)$$

**Ответ:** $$(6; 8)$$

---

### Задача 3.2 (ФИПИ)

**Условие:** Даны векторы $$\vec{a} = (5; 7)$$ и $$\vec{b} = (2; 3)$$ Найдите координаты вектора $$\vec{c} = \vec{a} - \vec{b}$$

**Решение:**

$$\vec{c} = (5 - 2; 7 - 3) = (3; 4)$$

**Ответ:** $$(3; 4)$$

---

### Задача 3.3 (ФИПИ - длина суммы)

**Условие:** Даны векторы $$\vec{a} = (1; 0)$$ и $$\vec{b} = (0; 1)$$ Найдите длину вектора $$\vec{a} + \vec{b}$$

**Решение:**

$$\vec{a} + \vec{b} = (1; 1)$$

$$|\vec{a} + \vec{b}| = \sqrt{1^2 + 1^2} = \sqrt{2}$$

**Ответ:** $$\sqrt{2} \approx 1{,}41$$

---

## Прототип 4: Умножение вектора на число

### Задача 4.1 (ФИПИ)

**Условие:** Дан вектор $$\vec{a} = (3; 4)$$ Найдите координаты вектора $$\vec{b} = 2\vec{a}$$

**Решение:**

$$\vec{b} = 2 \cdot (3; 4) = (6; 8)$$

**Ответ:** $$(6; 8)$$

---

### Задача 4.2 (ФИПИ - длина)

**Условие:** Дан вектор $$\vec{a} = (2; 1)$$ Найдите длину вектора $$3\vec{a}$$

**Решение:**

$$3\vec{a} = (6; 3)$$

$$|3\vec{a}| = \sqrt{6^2 + 3^2} = \sqrt{36 + 9} = \sqrt{45} = 3\sqrt{5}$$

Или: $$|3\vec{a}| = 3 |\vec{a}| = 3 \sqrt{2^2 + 1^2} = 3\sqrt{5}$$

**Ответ:** $$3\sqrt{5} \approx 6{,}71$$

---

## Прототип 5: Коллинеарность векторов

### Задача 5.1 (ФИПИ)

**Условие:** При каком значении $$k$$ векторы $$\vec{a} = (2; 3)$$ и $$\vec{b} = (4; k)$$ коллинеарны?

**Решение:**

Векторы коллинеарны, если $$\vec{b} = \lambda \vec{a}$$:

$$\frac{4}{2} = \frac{k}{3}$$

$$2 = \frac{k}{3}$$

$$k = 6$$

**Ответ:** $$6$$

---

### Задача 5.2 (ФИПИ - найти коэффициент)

**Условие:** Векторы $$\vec{a} = (3; 6)$$ и $$\vec{b} = (1; 2)$$ коллинеарны. Найдите коэффициент $$\lambda$$, если $$\vec{a} = \lambda \vec{b}$$

**Решение:**

$$\frac{3}{1} = \frac{6}{2} = 3$$

$$\lambda = 3$$

**Ответ:** $$3$$

## Прототип 6: Координаты середины отрезка

### Задача 6.1 (ФИПИ)

**Условие:** Найдите координаты середины отрезка $$AB$$, если $$A(2; 4)$$ и $$B(6; 8)$$

**Решение:**

$$M\left(\frac{2 + 6}{2}; \frac{4 + 8}{2}\right) = M(4; 6)$$

**Ответ:** $$(4; 6)$$

---

### Задача 6.2 (ФИПИ - в пространстве)

**Условие:** Найдите координату $$z$$ середины отрезка $$AB$$, если $$A(1; 2; 3)$$ и $$B(5; 6; 9)$$

**Решение:**

$$z_M = \frac{3 + 9}{2} = \frac{12}{2} = 6$$

**Ответ:** $$6$$

---

## Прототип 7: Комбинированные задачи (длина суммы/разности)

### Задача 7.1 (ФИПИ - длина суммы векторов)

**Условие:** Даны векторы $$\vec{a} = (3; 4)$$ и $$\vec{b} = (1; 2)$$ Найдите длину вектора $$\vec{c} = 2\vec{a} - \vec{b}$$

**Решение:**

$$2\vec{a} = (6; 8)$$

$$\vec{c} = (6; 8) - (1; 2) = (5; 6)$$

$$|\vec{c}| = \sqrt{5^2 + 6^2} = \sqrt{25 + 36} = \sqrt{61}$$

**Ответ:** $$\sqrt{61} \approx 7{,}81$$

---

## Прототип 8: Задачи на координатной сетке (векторы)

### Задача 8.1 (ФИПИ - векторы на клетчатой бумаге)

**Условие:** На клетчатой бумаге изображены векторы $$\vec{a}$$ и $$\vec{b}$$ Вектор $$\vec{a}$$ имеет координаты $$(2; 1)$$, вектор $$\vec{b}$$ - $$(1; 3)$$ Найдите длину вектора $$\vec{a} + \vec{b}$$

**Решение:**

$$\vec{a} + \vec{b} = (2 + 1; 1 + 3) = (3; 4)$$

$$|\vec{a} + \vec{b}| = \sqrt{3^2 + 4^2} = 5$$

**Ответ:** $$5$$

## Ловушки и частые ошибки

1. **Неправильный порядок вычитания координат:** $$\overrightarrow{AB} = B - A$$, а не $$A - B$$
2. **Забывают извлечь корень при нахождении длины вектора**
3. **При проверке коллинеарности неправильно составляют пропорцию**
4. **Неправильно считают координаты середины отрезка (забывают делить на 2)**
