## Прототип 1: Квадратные уравнения

### Задача 1.1 (ФИПИ)

**Условие:** Решите уравнение $$x^2 - 7x + 12 = 0$$.

**Решение:**

$$D = 49 - 48 = 1$$

$$x_{1,2} = \frac{7 \pm 1}{2} = 4, 3$$

**Ответ:** $$3; 4$$

---

### Задача 1.2 (ФИПИ)

**Условие:** Решите уравнение $$x^2 - 6x + 9 = 0$$.

**Решение:**

$$D = 36 - 36 = 0$$

$$x = \frac{6}{2} = 3$$

**Ответ:** $$3$$

---

### Задача 1.3 (ФИПИ — через Виета)

**Условие:** Решите уравнение $$x^2 - 5x + 6 = 0$$.

**Решение (через Виета):**

Нужно найти два числа, сумма которых равна 5, а произведение — 6.

Это числа 2 и 3.

$$x_1 = 2, \quad x_2 = 3$$

**Ответ:** $$2; 3$$

---

### Задача 1.4 (ФИПИ — неполное квадратное)

**Условие:** Решите уравнение $$x^2 - 16 = 0$$.

**Решение:**

$$x^2 = 16$$

$$x = \pm 4$$

**Ответ:** $$-4; 4$$

---

### Задача 1.5 (ФИПИ — неполное квадратное с вынесением)

**Условие:** Решите уравнение $$x^2 - 5x = 0$$.

**Решение:**

$$x(x - 5) = 0$$

$$x = 0 \text{ или } x = 5$$

**Ответ:** $$0; 5$$

## Прототип 2: Дробно-рациональные уравнения

### Задача 2.1 (ФИПИ)

**Условие:** Решите уравнение $$\frac{x^2 - 4}{x - 3} = 0$$.

**Решение:**

ОДЗ: $$x \neq 3$$

$$x^2 - 4 = 0$$

$$x = \pm 2$$

Оба корня входят в ОДЗ.

**Ответ:** $$-2; 2$$

---

### Задача 2.2 (ФИПИ)

**Условие:** Решите уравнение $$\frac{x^2 - 9}{x + 3} = 0$$.

**Решение:**

ОДЗ: $$x \neq -3$$

$$x^2 - 9 = 0$$

$$x = \pm 3$$

Корень $$x = -3$$ не входит в ОДЗ.

**Ответ:** $$3$$

---

### Задача 2.3 (ФИПИ — с сокращением)

**Условие:** Решите уравнение $$\frac{x^2 - 5x + 6}{x - 2} = 0$$.

**Решение:**

ОДЗ: $$x \neq 2$$

$$x^2 - 5x + 6 = 0$$

$$(x - 2)(x - 3) = 0$$

$$x = 2 \text{ или } x = 3$$

Корень $$x = 2$$ не входит в ОДЗ.

**Ответ:** $$3$$

---

### Задача 2.4 (ФИПИ — дробь равна числу)

**Условие:** Решите уравнение $$\frac{x + 5}{x - 1} = 3$$.

**Решение:**

ОДЗ: $$x \neq 1$$

$$x + 5 = 3(x - 1)$$

$$x + 5 = 3x - 3$$

$$8 = 2x$$

$$x = 4$$

Проверка: $$\frac{4 + 5}{4 - 1} = \frac{9}{3} = 3$$ — верно.

**Ответ:** $$4$$

## Прототип 3: Иррациональные уравнения

### Задача 3.1 (ФИПИ)

**Условие:** Решите уравнение $$\sqrt{x + 7} = 4$$.

**Решение:**

ОДЗ: $$x + 7 \geq 0 \Rightarrow x \geq -7$$

$$x + 7 = 16$$

$$x = 9$$

Проверка: $$\sqrt{9 + 7} = \sqrt{16} = 4$$ — верно.

**Ответ:** $$9$$

---

### Задача 3.2 (ФИПИ)

**Условие:** Решите уравнение $$\sqrt{2x - 3} = x - 3$$.

**Решение:**

ОДЗ: $$2x - 3 \geq 0 \Rightarrow x \geq 1{,}5$$ и $$x - 3 \geq 0 \Rightarrow x \geq 3$$

Итого: $$x \geq 3$$

$$2x - 3 = (x - 3)^2$$

$$2x - 3 = x^2 - 6x + 9$$

$$x^2 - 8x + 12 = 0$$

$$D = 64 - 48 = 16$$

$$x_{1,2} = \frac{8 \pm 4}{2} = 6, 2$$

Корень $$x = 2$$ не входит в ОДЗ ($$2 < 3$$).

Проверка для $$x = 6$$: $$\sqrt{12 - 3} = \sqrt{9} = 3$$, $$6 - 3 = 3$$ — верно.

**Ответ:** $$6$$

---

### Задача 3.3 (ФИПИ — с переносом)

**Условие:** Решите уравнение $$\sqrt{x + 12} = x$$.

**Решение:**

ОДЗ: $$x + 12 \geq 0 \Rightarrow x \geq -12$$ и $$x \geq 0$$

Итого: $$x \geq 0$$

$$x + 12 = x^2$$

$$x^2 - x - 12 = 0$$

$$D = 1 + 48 = 49$$

$$x_{1,2} = \frac{1 \pm 7}{2} = 4, -3$$

Корень $$x = -3$$ не входит в ОДЗ.

Проверка для $$x = 4$$: $$\sqrt{4 + 12} = \sqrt{16} = 4$$ — верно.

**Ответ:** $$4$$

## Прототип 4: Показательные уравнения

### Задача 4.1 (ФИПИ)

**Условие:** Решите уравнение $$2^{x+3} = 32$$.

**Решение:**

$$2^{x+3} = 2^5$$

$$x + 3 = 5$$

$$x = 2$$

**Ответ:** $$2$$

---

### Задача 4.2 (ФИПИ)

**Условие:** Решите уравнение $$5^{2x-1} = 125$$.

**Решение:**

$$5^{2x-1} = 5^3$$

$$2x - 1 = 3$$

$$2x = 4$$

$$x = 2$$

**Ответ:** $$2$$

---

### Задача 4.3 (ФИПИ — с дробью)

**Условие:** Решите уравнение $$3^{x-2} = \frac{1}{9}$$.

**Решение:**

$$3^{x-2} = 3^{-2}$$

$$x - 2 = -2$$

$$x = 0$$

**Ответ:** $$0$$

---

### Задача 4.4 (ФИПИ — с корнем)

**Условие:** Решите уравнение $$4^x = 8$$.

**Решение:**

$$2^{2x} = 2^3$$

$$2x = 3$$

$$x = 1{,}5$$

**Ответ:** $$1{,}5$$

## Прототип 5: Логарифмические уравнения

### Задача 5.1 (ФИПИ)

**Условие:** Решите уравнение $$\log_3 (x + 2) = 2$$.

**Решение:**

ОДЗ: $$x + 2 > 0 \Rightarrow x > -2$$

$$x + 2 = 3^2 = 9$$

$$x = 7$$

**Ответ:** $$7$$

---

### Задача 5.2 (ФИПИ)

**Условие:** Решите уравнение $$\log_2 (x - 1) = 3$$.

**Решение:**

ОДЗ: $$x - 1 > 0 \Rightarrow x > 1$$

$$x - 1 = 2^3 = 8$$

$$x = 9$$

**Ответ:** $$9$$

---

### Задача 5.3 (ФИПИ — с одинаковыми основаниями)

**Условие:** Решите уравнение $$\log_5 (x + 3) = \log_5 7$$.

**Решение:**

ОДЗ: $$x + 3 > 0 \Rightarrow x > -3$$

$$x + 3 = 7$$

$$x = 4$$

**Ответ:** $$4$$

---

### Задача 5.4 (ФИПИ — логарифм произведения)

**Условие:** Решите уравнение $$\log_2 x + \log_2 (x - 3) = 2$$.

**Решение:**

ОДЗ: $$x > 0$$ и $$x - 3 > 0 \Rightarrow x > 3$$

$$\log_2 (x(x - 3)) = 2$$

$$x(x - 3) = 4$$

$$x^2 - 3x - 4 = 0$$

$$D = 9 + 16 = 25$$

$$x_{1,2} = \frac{3 \pm 5}{2} = 4, -1$$

Корень $$x = -1$$ не входит в ОДЗ.

**Ответ:** $$4$$

## Прототип 6: Тригонометрические уравнения

### Задача 6.1 (ФИПИ)

**Условие:** Решите уравнение $$\sin x = \frac{\sqrt{2}}{2}$$. Найдите корни на отрезке $$[0; 2\pi]$$.

**Решение:**

$$x = \frac{\pi}{4}, \frac{3\pi}{4}$$

**Ответ:** $$\frac{\pi}{4}; \frac{3\pi}{4}$$

---

### Задача 6.2 (ФИПИ)

**Условие:** Решите уравнение $$\cos x = -\frac{1}{2}$$. Найдите корни на отрезке $$[0; 2\pi]$$.

**Решение:**

$$x = \frac{2\pi}{3}, \frac{4\pi}{3}$$

**Ответ:** $$\frac{2\pi}{3}; \frac{4\pi}{3}$$

---

### Задача 6.3 (ФИПИ)

**Условие:** Решите уравнение $$\tan x = 1$$. Найдите корни на отрезке $$[0; \pi]$$.

**Решение:**

$$x = \frac{\pi}{4}$$

**Ответ:** $$\frac{\pi}{4}$$

---

### Задача 6.4 (ФИПИ — с коэффициентом)

**Условие:** Решите уравнение $$\sin 2x = 0$$. Найдите корни на отрезке $$[0; \pi]$$.

**Решение:**

$$2x = \pi n, \quad n \in \mathbb{Z}$$

$$x = \frac{\pi n}{2}$$

На отрезке $$[0; \pi]$$: $$x = 0, \frac{\pi}{2}, \pi$$

**Ответ:** $$0; \frac{\pi}{2}; \pi$$

---

### Задача 6.5 (ФИПИ — квадратное тригонометрическое)

**Условие:** Решите уравнение $$2\sin^2 x - \sin x = 0$$. Найдите корни на отрезке $$[0; 2\pi]$$.

**Решение:**

$$\sin x (2\sin x - 1) = 0$$

$$\sin x = 0 \text{ или } \sin x = \frac{1}{2}$$

Для $$\sin x = 0$$: $$x = 0, \pi, 2\pi$$

Для $$\sin x = \frac{1}{2}$$: $$x = \frac{\pi}{6}, \frac{5\pi}{6}$$

**Ответ:** $$0; \frac{\pi}{6}; \frac{5\pi}{6}; \pi; 2\pi$$

## Ловушки и частые ошибки

1. **В дробно-рациональных уравнениях забывают проверить ОДЗ** (знаменатель не равен нулю)
2. **В иррациональных уравнениях не проверяют корни после возведения в квадрат** (могут появиться посторонние корни)
3. **В показательных уравнениях неправильно приводят к одному основанию**
4. **В логарифмических уравнениях забывают ОДЗ** (аргумент логарифма должен быть положительным)
5. **В тригонометрических уравнениях забывают найти все корни на заданном отрезке**
6. **Путают формулы для $$\sin x = a$$ и $$\cos x = a$$**
7. **При решении квадратных уравнений неправильно вычисляют дискриминант**
8. **Забывают, что при $$D < 0$$ нет действительных корней**
