## 1. Линейные уравнения

**Общий вид:**

$$ax + b = 0$$

**Решение:**

$$x = -\frac{b}{a}, \quad a \neq 0$$

---

## 2. Квадратные уравнения

**Общий вид:**

$$ax^2 + bx + c = 0, \quad a \neq 0$$

### 2.1. Через дискриминант

$$D = b^2 - 4ac$$

**Если $$D > 0$$:** два различных корня

$$x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$$

**Если $$D = 0$$:** один корень (два совпадающих)

$$x = \frac{-b}{2a}$$

**Если $$D < 0$$:** нет действительных корней

### 2.2. Теорема Виета

Для уравнения $$x^2 + px + q = 0$$:

$$x_1 + x_2 = -p$$

$$x_1 \cdot x_2 = q$$

### 2.3. Неполные квадратные уравнения

**Если $$b = 0$$:** $$ax^2 + c = 0$$

$$x^2 = -\frac{c}{a}$$

**Если $$c = 0$$:** $$ax^2 + bx = 0$$

$$x(ax + b) = 0 \Rightarrow x = 0 \text{ или } x = -\frac{b}{a}$$

---

## 3. Дробно-рациональные уравнения

**Общий вид:**

$$\frac{P(x)}{Q(x)} = 0$$

**Метод решения:**
1. Найти ОДЗ: $$Q(x) \neq 0$$
2. Приравнять числитель к нулю: $$P(x) = 0$$
3. Проверить корни на принадлежность ОДЗ

**Пример:**

$$\frac{x^2 - 4}{x - 1} = 0$$

ОДЗ: $$x \neq 1$$

$$x^2 - 4 = 0 \Rightarrow x = \pm 2$$

Оба корня входят в ОДЗ.

---

## 4. Иррациональные уравнения

**Общий вид:**

$$\sqrt{f(x)} = g(x)$$

**Метод решения:**
1. Найти ОДЗ: $$f(x) \geq 0$$, $$g(x) \geq 0$$
2. Возвести обе части в квадрат: $$f(x) = g^2(x)$$
3. Решить полученное уравнение
4. Проверить корни на принадлежность ОДЗ

**Пример:**

$$\sqrt{x + 3} = 2$$

ОДЗ: $$x + 3 \geq 0 \Rightarrow x \geq -3$$

$$x + 3 = 4 \Rightarrow x = 1$$

Проверка: $$\sqrt{1 + 3} = 2$$ — верно.

---

## 5. Показательные уравнения

**Общий вид:**

$$a^{f(x)} = a^{g(x)}$$

**Метод решения:** приравнять показатели

$$f(x) = g(x)$$

**Пример:**

$$2^{x+1} = 2^5$$

$$x + 1 = 5 \Rightarrow x = 4$$

**Если основания разные:**

$$a^{f(x)} = b^{g(x)}$$

Прологарифмировать обе части или привести к одному основанию.

**Пример:**

$$2^x = 8 \Rightarrow 2^x = 2^3 \Rightarrow x = 3$$

---

## 6. Логарифмические уравнения

**Общий вид:**

$$\log_a f(x) = \log_a g(x)$$

**Метод решения:**
1. Найти ОДЗ: $$f(x) > 0$$, $$g(x) > 0$$, $$a > 0$$, $$a \neq 1$$
2. Приравнять аргументы: $$f(x) = g(x)$$
3. Проверить корни на принадлежность ОДЗ

**Пример:**

$$\log_2 (x + 1) = \log_2 5$$

ОДЗ: $$x + 1 > 0 \Rightarrow x > -1$$

$$x + 1 = 5 \Rightarrow x = 4$$

**Основные свойства логарифмов:**

$$\log_a (xy) = \log_a x + \log_a y$$

$$\log_a \frac{x}{y} = \log_a x - \log_a y$$

$$\log_a x^n = n \log_a x$$

$$\log_a a = 1$$

$$\log_a 1 = 0$$

$$a^{\log_a x} = x$$

## 7. Тригонометрические уравнения

### 7.1. Простейшие уравнения

**$$\sin x = a$$, где $$|a| \leq 1$$:**

$$x = (-1)^n \arcsin a + \pi n, \quad n \in \mathbb{Z}$$

**Частные случаи:**
- $$\sin x = 0 \Rightarrow x = \pi n$$
- $$\sin x = 1 \Rightarrow x = \frac{\pi}{2} + 2\pi n$$
- $$\sin x = -1 \Rightarrow x = -\frac{\pi}{2} + 2\pi n$$

**$$\cos x = a$$, где $$|a| \leq 1$$:**

$$x = \pm \arccos a + 2\pi n, \quad n \in \mathbb{Z}$$

**Частные случаи:**
- $$\cos x = 0 \Rightarrow x = \frac{\pi}{2} + \pi n$$
- $$\cos x = 1 \Rightarrow x = 2\pi n$$
- $$\cos x = -1 \Rightarrow x = \pi + 2\pi n$$

**$$\tan x = a$$:**

$$x = \arctan a + \pi n, \quad n \in \mathbb{Z}$$

**Частные случаи:**
- $$\tan x = 0 \Rightarrow x = \pi n$$
- $$\tan x = 1 \Rightarrow x = \frac{\pi}{4} + \pi n$$
- $$\tan x = -1 \Rightarrow x = -\frac{\pi}{4} + \pi n$$

**$$\cot x = a$$:**

$$x = \text{arccot}\, a + \pi n, \quad n \in \mathbb{Z}$$

### 7.2. Основные тригонометрические формулы

**Основное тригонометрическое тождество:**

$$\sin^2 x + \cos^2 x = 1$$

**Формулы двойного угла:**

$$\sin 2x = 2 \sin x \cos x$$

$$\cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$$

$$\tan 2x = \frac{2 \tan x}{1 - \tan^2 x}$$

**Формулы понижения степени:**

$$\sin^2 x = \frac{1 - \cos 2x}{2}$$

$$\cos^2 x = \frac{1 + \cos 2x}{2}$$

**Формулы суммы и разности:**

$$\sin(x \pm y) = \sin x \cos y \pm \cos x \sin y$$

$$\cos(x \pm y) = \cos x \cos y \mp \sin x \sin y$$

$$\tan(x \pm y) = \frac{\tan x \pm \tan y}{1 \mp \tan x \tan y}$$

## 8. Типичные задачи ЕГЭ №6 (уравнения)

### Задача 1: Квадратное уравнение

**Пример:** Решите уравнение $$x^2 - 5x + 6 = 0$$.

$$D = 25 - 24 = 1$$

$$x_{1,2} = \frac{5 \pm 1}{2} = 3, 2$$

### Задача 2: Дробно-рациональное уравнение

**Пример:** Решите уравнение $$\frac{x^2 - 9}{x + 2} = 0$$.

ОДЗ: $$x \neq -2$$

$$x^2 - 9 = 0 \Rightarrow x = \pm 3$$

### Задача 3: Иррациональное уравнение

**Пример:** Решите уравнение $$\sqrt{x + 5} = 3$$.

$$x + 5 = 9 \Rightarrow x = 4$$

### Задача 4: Показательное уравнение

**Пример:** Решите уравнение $$3^{x+2} = 27$$.

$$3^{x+2} = 3^3 \Rightarrow x + 2 = 3 \Rightarrow x = 1$$

### Задача 5: Логарифмическое уравнение

**Пример:** Решите уравнение $$\log_5 (x - 1) = 2$$.

$$x - 1 = 5^2 = 25 \Rightarrow x = 26$$

### Задача 6: Тригонометрическое уравнение

**Пример:** Решите уравнение $$\sin x = \frac{1}{2}$$ на отрезке $$[0; 2\pi]$$.

$$x = \frac{\pi}{6}, \frac{5\pi}{6}$$
