## 1. Основные формулы и определения

### 1.1. Область допустимых значений (ОДЗ)

**Определение:** ОДЗ — это множество всех значений переменной, при которых выражение имеет смысл.

**Правила нахождения ОДЗ:**

**Для дробей:**
$$g(x) \neq 0$$ — знаменатель не равен нулю

**Для корней четной степени:**
$$f(x) \geq 0$$ — подкоренное выражение неотрицательно

**Для логарифмов:**
- Аргумент положителен: $$f(x) > 0$$
- Основание положительно и не равно 1: $$a > 0, a \neq 1$$

**Для показательных функций:**
- Основание положительно: $$a > 0, a \neq 1$$

**Пример:** Найти ОДЗ для $$\log_2(x-1) + \sqrt{x+3}$$
- $$x - 1 > 0 \to x > 1$$
- $$x + 3 \geq 0 \to x \geq -3$$
- ОДЗ: $$x \in (1; +\infty)$$

---

### 1.2. Свойства логарифмической функции

**Монотонность при основании $$a > 1$$:**
$$f(x) > g(x) > 0 \iff \log_a(f(x)) > \log_a(g(x))$$

**Монотонность при основании $$0 < a < 1$$:**
$$0 < f(x) < g(x) \iff \log_a(f(x)) > \log_a(g(x))$$

**Основные формулы:**
$$\log_a(xy) = \log_a(x) + \log_a(y), \quad x > 0, y > 0$$
$$\log_a\left(\frac{x}{y}\right) = \log_a(x) - \log_a(y), \quad x > 0, y > 0$$
$$\log_a(x^n) = n \cdot \log_a(x), \quad x > 0$$
$$\log_a(b) = \frac{\log_c(b)}{\log_c(a)}, \quad a > 0, a \neq 1, c > 0, c \neq 1$$

---

### 1.3. Свойства показательной функции

**Монотонность при основании $$a > 1$$:**
$$f(x) > g(x) \iff a^{f(x)} > a^{g(x)}$$

**Монотонность при основании $$0 < a < 1$$:**
$$f(x) < g(x) \iff a^{f(x)} > a^{g(x)}$$

**Основные формулы:**
$$a^m \cdot a^n = a^{m+n}$$
$$a^m / a^n = a^{m-n}, \quad a \neq 0$$
$$(a^m)^n = a^{mn}$$
$$(ab)^n = a^n \cdot b^n$$

## 2. Основные методы решения

### 2.1. Метод интервалов

**Что применяется для:** Рациональные, дробно-рациональные неравенства, а также неравенства после рационализации.

**Алгоритм:**
1. Найти нули числителя и знаменателя
2. Отметить их на числовой прямой
3. Определить знаки на каждом интервале (подставить пробное значение)
4. Выбрать интервалы в соответствии со знаком неравенства

**Правило знаков:**
- При переходе через нуль нечетной кратности знак меняется
- При переходе через нуль четной кратности знак сохраняется

**Пример:** Решить $$\frac{(x-1)(x-3)}{x-2} \geq 0$$
- Нули: $$x = 1, x = 2, x = 3$$
- Знаки: $$(-\infty; 1): (-), (1; 2): (+), (2; 3): (-), (3; +\infty): (+)$$
- Ответ: $$x \in [1; 2) \cup [3; +\infty)$$

---

### 2.2. Метод рационализации

**Что это:** Замена логарифмических и показательных неравенств на равносильные рациональные неравенства.

**Основные формулы рационализации:**

**Для логарифмов ($$a > 0, a \neq 1$$):**
$$\log_a(f(x)) - \log_a(g(x)) \iff (a-1)(f(x) - g(x))$$

**Для показательных функций:**
$$a^{f(x)} - a^{g(x)} \iff (a-1)(f(x) - g(x))$$

**Для модулей:**
$$|f(x)| - |g(x)| \iff (f(x) - g(x))(f(x) + g(x))$$

**Условие применения:** Все выражения должны быть определены на ОДЗ.

**Пример:** Решить $$\log_2(x-1) - \log_2(x+1) > 0$$
1. ОДЗ: $$x > 1$$
2. Рационализация: $$(2-1)((x-1) - (x+1)) > 0$$
3. Упрощение: $$-2 > 0$$ — неверно
4. Ответ: решений нет

## 3. Типичные задачи ЕГЭ (Задание 15)

### 3.1. Простые логарифмические неравенства

**Тип задачи:** Неравенство вида $$\log_a(f(x)) \gtrless c$$ или $$\log_a(f(x)) \gtrless \log_a(g(x))$$

**Алгоритм решения:**
1. Найти ОДЗ
2. Привести к одному основанию (если нужно)
3. Использовать монотонность функции
4. Решить полученное неравенство
5. Учесть ОДЗ в ответе

**Пример:** Решить $$\log_2(x-1) < 3$$

**Решение:**
1. ОДЗ: $$x - 1 > 0 \to x > 1$$
2. Переходим к показательному виду: $$x - 1 < 2^3 = 8$$
3. $$x < 9$$
4. Пересечение с ОДЗ: $$x \in (1; 9)$$

**Ответ:** $$x \in (1; 9)$$

---

### 3.2. Логарифмические неравенства с разными основаниями

**Тип задачи:** Неравенство вида $$\log_{a}(f(x)) \gtrless \log_{b}(g(x))$$

**Алгоритм решения:**
1. Найти ОДЗ для всех логарифмов
2. Привести к одному основанию через формулу перехода
3. Применить метод рационализации или монотонность
4. Решить полученное неравенство

**Пример:** Решить $$\log_2(x-1) > \log_3(x+1)$$

**Решение:**
1. ОДЗ: $$x > 1$$
2. Переходим к основанию 10: $$\frac{\lg(x-1)}{\lg 2} > \frac{\lg(x+1)}{\lg 3}$$
3. Умножаем на положительные числа: $$\lg(x-1) \cdot \lg 3 > \lg(x+1) \cdot \lg 2$$
4. Применяем рационализацию или решаем численно

---

### 3.3. Показательные неравенства

**Тип задачи:** Неравенство вида $$a^{f(x)} \gtrless a^{g(x)}$$ или $$a^{f(x)} \gtrless c$$

**Алгоритм решения:**
1. Найти ОДЗ (если есть ограничения)
2. Привести к одному основанию (если возможно)
3. Использовать монотонность показательной функции
4. Решить полученное неравенство

**Пример:** Решить $$2^{x+1} > 8$$

**Решение:**
1. Приводим правую часть: $$2^{x+1} > 2^3$$
2. Основание $$2 > 1$$, функция возрастает: $$x + 1 > 3$$
3. $$x > 2$$

**Ответ:** $$x \in (2; +\infty)$$

---

### 3.4. Комбинированные неравенства (метод рационализации)

**Тип задачи:** Неравенство с несколькими логарифмами или показательными функциями.

**Алгоритм решения:**
1. Найти ОДЗ
2. Применить метод рационализации для каждого слагаемого
3. Привести к общему знаменателю
4. Применить метод интервалов
5. Учесть ОДЗ в ответе

**Пример:** Решить $$\log_2(x-1) - \log_2(x+1) + \log_3(x-2) > 0$$

**Решение:**
1. ОДЗ: $$x > 2$$
2. Рационализация:
   - $$\log_2(x-1) - \log_2(x+1) \iff (2-1)((x-1) - (x+1)) = -2$$
   - $$\log_3(x-2) \iff (3-1)(x-2-1) = 2(x-3)$$ (при сравнении с 0)
3. Получаем: $$-2 + 2(x-3) > 0$$
4. $$2x - 8 > 0 \to x > 4$$
5. С учетом ОДЗ: $$x \in (4; +\infty)$$

---

### 3.5. Неравенства с переменным основанием

**Тип задачи:** Неравенство вида $$\log_{f(x)}(g(x)) \gtrless c$$

**Алгоритм решения:**
1. Найти ОДЗ (аргумент > 0, основание > 0 и ≠ 1)
2. Разбить на случаи по основанию:
   - Случай 1: $$f(x) > 1$$ (функция возрастает)
   - Случай 2: $$0 < f(x) < 1$$ (функция убывает)
3. Решить неравенство в каждом случае
4. Объединить решения с учетом ОДЗ

**Пример:** Решить $$\log_{x-1}(x+2) > 1$$

**Решение:**
1. ОДЗ: $$x > 1, x \neq 2$$
2. Случай 1: $$x - 1 > 1$$, т.е. $$x > 2$$
   - $$\log_{x-1}(x+2) > \log_{x-1}(x-1)$$
   - $$x + 2 > x - 1 \to 2 > -1$$ — верно для всех $$x > 2$$
3. Случай 2: $$1 < x < 2$$
   - $$x + 2 < x - 1 \to 2 < -1$$ — неверно
4. Ответ: $$x \in (2; +\infty)$$

## 4. Алгоритм решения неравенств на ЕГЭ

### Шаг 1: Анализ условия
- Определить тип неравенства (логарифмическое, показательное, комбинированное)
- Выявить все ограничения
- Определить, можно ли применить рационализацию

### Шаг 2: Нахождение ОДЗ
- Для каждого логарифма: аргумент > 0, основание > 0 и ≠ 1
- Для каждого корня: подкоренное выражение ≥ 0
- Для каждой дроби: знаменатель ≠ 0
- Объединить все ограничения

### Шаг 3: Выбор метода
- **Метод рационализации** — если есть разности логарифмов/показательных функций
- **Метод интервалов** — если после преобразований получилось рациональное неравенство
- **Монотонность** — если можно привести к одному основанию

### Шаг 4: Решение
- Применить выбранный метод
- Решить полученное неравенство
- Учесть все ограничения

### Шаг 5: Проверка
- Проверить, что все решения входят в ОДЗ
- Проверить граничные точки (для нестрогих неравенств)
- Убедиться, что ответ записан в требуемом формате

## 5. Типичные ошибки и как их избежать

### Ошибка 1: Забыли ОДЗ
**Проблема:** Решили неравенство, но не учли ограничения на переменную.

**Как избежать:** 
- Всегда начинать с нахождения ОДЗ
- В конце проверять пересечение решения с ОДЗ

**Пример:** 
- Неправильно: $$\log_2(x-1) < 3 \to x < 9$$
- Правильно: $$\log_2(x-1) < 3 \to x \in (1; 9)$$ (учтено $$x > 1$$)

---

### Ошибка 2: Неправильный знак при основании < 1
**Проблема:** Не учитывают, что при $$0 < a < 1$$ знак неравенства меняется.

**Как избежать:** 
- Всегда проверять основание перед применением монотонности
- Если $$0 < a < 1$$, знак неравенства меняется на противоположный

**Пример:**
- Неправильно: $$\log_{\frac{1}{2}}(x) > \log_{\frac{1}{2}}(3) \to x > 3$$
- Правильно: $$\log_{\frac{1}{2}}(x) > \log_{\frac{1}{2}}(3) \to x < 3$$ (знак изменился)

---

### Ошибка 3: Неправильное применение рационализации
**Проблема:** Применяют рационализацию без учета ОДЗ или в неподходящих случаях.

**Как избежать:** 
- Проверять, что все выражения определены на ОДЗ
- Использовать рационализацию только для разностей однотипных функций

**Пример:**
- Неправильно: $$\log_2(x-1) + 5 > 0$$ нельзя рационализировать (нет разности)
- Правильно: $$\log_2(x-1) - \log_2(x+1) > 0$$ можно рационализировать

---

### Ошибка 4: Не учли переменное основание
**Проблема:** Решают неравенство с переменным основанием без разбиения на случаи.

**Как избежать:** 
- Всегда разбивать на случаи: основание > 1 и 0 < основание < 1
- Учитывать, что основание ≠ 1

**Пример:**
- Неправильно: $$\log_{x-1}(x+2) > 1$$ решали без разбиения на случаи
- Правильно: разбить на $$x > 2$$ и $$1 < x < 2$$

---

### Ошибка 5: Неправильное сокращение в дробно-рациональных
**Проблема:** После рационализации получилось дробно-рациональное неравенство, но забыли проверить точки из ОДЗ.

**Как избежать:** 
- После сокращения проверять, не теряются ли точки из ОДЗ
- Всегда проверять граничные точки

**Пример:**
- Неправильно: $$\frac{x-2}{x-2} \leq 0$$ сократили до $$1 \leq 0$$, забыв про $$x \neq 2$$
- Правильно: $$\frac{x-2}{x-2} \leq 0$$ при $$x \neq 2$$ не имеет решений

---

## 6. Классические конструкции примеров

### Конструкция 1: $$\log_a(f(x)) \gtrless c$$
**Типичный вид:** $$\log_2(x-1) < 3$$

**Решение:**
1. ОДЗ: $$f(x) > 0$$
2. Переход к показательному виду: $$f(x) \gtrless a^c$$
3. Учесть ОДЗ

---

### Конструкция 2: $$\log_a(f(x)) \gtrless \log_a(g(x))$$
**Типичный вид:** $$\log_3(x-2) > \log_3(5)$$

**Решение:**
1. ОДЗ: $$f(x) > 0, g(x) > 0$$
2. Если $$a > 1$$: $$f(x) \gtrless g(x)$$
3. Если $$0 < a < 1$$: знак меняется
4. Учесть ОДЗ

---

### Конструкция 3: $$\log_a(f(x)) - \log_a(g(x)) \gtrless 0$$
**Типичный вид:** $$\log_2(x-1) - \log_2(x+1) > 0$$

**Решение:**
1. ОДЗ: $$f(x) > 0, g(x) > 0$$
2. Рационализация: $$(a-1)(f(x) - g(x)) \gtrless 0$$
3. Метод интервалов
4. Учесть ОДЗ

---

### Конструкция 4: $$a^{f(x)} \gtrless a^{g(x)}$$
**Типичный вид:** $$2^{x+1} > 2^{x-1}$$

**Решение:**
1. ОДЗ (если есть ограничения)
2. Если $$a > 1$$: $$f(x) \gtrless g(x)$$
3. Если $$0 < a < 1$$: знак меняется

---

### Конструкция 5: $$a^{f(x)} - a^{g(x)} \gtrless 0$$
**Типичный вид:** $$3^{x+1} - 3^{x-1} > 0$$

**Решение:**
1. ОДЗ (если есть ограничения)
2. Рационализация: $$(a-1)(f(x) - g(x)) \gtrless 0$$
3. Метод интервалов

---

### Конструкция 6: Комбинированные неравенства
**Типичный вид:** $$\log_2(x-1) + \log_2(x+1) < 3$$

**Решение:**
1. ОДЗ: $$x > 1$$
2. Применить формулу суммы: $$\log_2((x-1)(x+1)) < 3$$
3. Переход к показательному виду: $$(x-1)(x+1) < 8$$
4. Решить квадратное неравенство
5. Учесть ОДЗ

---

## 7. Практические рекомендации

### Для быстрого решения:
1. **Запомните формулы рационализации:**
   - $$\log_a(f) - \log_a(g) \iff (a-1)(f-g)$$
   - $$a^f - a^g \iff (a-1)(f-g)$$

2. **Всегда начинайте с ОДЗ** — это сэкономит время и предотвратит ошибки

3. **Используйте метод интервалов** для рациональных неравенств после рационализации

4. **Проверяйте основание** перед применением монотонности

### Для сложных задач:
1. Разбивайте задачу на подзадачи
2. Используйте рационализацию для упрощения
3. Проверяйте граничные точки
4. Учитывайте все ограничения по отдельности
