## Прототип 1: Найти значение производной по графику функции

### Задача 1.1 (ФИПИ)

**Условие:** На рисунке изображён график функции $$y = f(x)$$. Найдите значение производной функции в точке $$x_0 = 2$$.

**Решение:**

Производная в точке равна угловому коэффициенту касательной к графику в этой точке.

Проведём касательную к графику в точке $$x_0 = 2$$ и найдём её угловой коэффициент:

$$k = \tan \alpha = \frac{\Delta y}{\Delta x}$$

Если касательная проходит через точки $$(2; 3)$$ и $$(4; 7)$$:

$$k = \frac{7 - 3}{4 - 2} = \frac{4}{2} = 2$$

**Ответ:** $$2$$

---

### Задача 1.2 (ФИПИ — отрицательная производная)

**Условие:** На рисунке изображён график функции $$y = f(x)$$. Найдите значение производной функции в точке $$x_0 = 1$$.

**Решение:**

Если касательная убывает (идёт вниз слева направо), производная отрицательна.

Касательная проходит через точки $$(1; 5)$$ и $$(3; 1)$$:

$$k = \frac{1 - 5}{3 - 1} = \frac{-4}{2} = -2$$

**Ответ:** $$-2$$

## Прототип 2: Найти количество точек экстремума по графику функции

### Задача 2.1 (ФИПИ)

**Условие:** На рисунке изображён график функции $$y = f(x)$$. Найдите количество точек экстремума функции на отрезке $$[-3; 5]$$.

**Решение:**

Точки экстремума — это точки, в которых производная меняет знак (точки максимума и минимума).

На графике видим:
- 2 точки максимума (вершины «горбов»)
- 1 точку минимума («дно впадины»)

Всего: $$3$$ точки экстремума.

**Ответ:** $$3$$

---

### Задача 2.2 (ФИПИ — только максимумы)

**Условие:** На рисунке изображён график функции $$y = f(x)$$. Найдите количество точек максимума функции на отрезке $$[-2; 4]$$.

**Решение:**

Точки максимума — это точки, в которых функция достигает локального наибольшего значения (вершины «горбов»).

На графике видим: $$2$$ точки максимума.

**Ответ:** $$2$$

---

## Прототип 3: Найти количество точек, где производная равна нулю, по графику производной

### Задача 3.1 (ФИПИ)

**Условие:** На рисунке изображён график производной $$y = f'(x)$$ функции $$f(x)$$. Найдите количество точек, в которых производная равна нулю, на отрезке $$[-5; 5]$$.

**Решение:**

Производная равна нулю в точках, где график $$f'(x)$$ пересекает ось $$Ox$$.

Считаем точки пересечения: $$4$$ точки.

**Ответ:** $$4$$

---

### Задача 3.2 (ФИПИ — точки экстремума по графику производной)

**Условие:** На рисунке изображён график производной $$y = f'(x)$$. Найдите количество точек экстремума функции $$f(x)$$ на отрезке $$[-3; 3]$$.

**Решение:**

Точки экстремума функции $$f(x)$$ — это точки, где $$f'(x) = 0$$ и производная меняет знак.

Считаем точки пересечения графика $$f'(x)$$ с осью $$Ox$$, где происходит смена знака: $$3$$ точки.

**Ответ:** $$3$$

---

## Прототип 4: Найти промежутки возрастания/убывания по графику производной

### Задача 4.1 (ФИПИ)

**Условие:** На рисунке изображён график производной $$y = f'(x)$$. Найдите длину промежутка возрастания функции $$f(x)$$.

**Решение:**

Функция возрастает, когда $$f'(x) > 0$$ (график производной выше оси $$Ox$$).

На графике видим, что $$f'(x) > 0$$ на промежутке $$[-2; 3]$$.

Длина промежутка: $$3 - (-2) = 5$$.

**Ответ:** $$5$$

---

### Задача 4.2 (ФИПИ — убывание)

**Условие:** На рисунке изображён график производной $$y = f'(x)$$. Найдите количество промежутков убывания функции $$f(x)$$.

**Решение:**

Функция убывает, когда $$f'(x) < 0$$ (график производной ниже оси $$Ox$$).

На графике видим $$2$$ промежутка, где $$f'(x) < 0$$.

**Ответ:** $$2$$

---

## Прототип 5: Найти точку минимума/максимума по графику производной

### Задача 5.1 (ФИПИ)

**Условие:** На рисунке изображён график производной $$y = f'(x)$$. Найдите точку минимума функции $$f(x)$$ на отрезке $$[-4; 4]$$.

**Решение:**

Точка минимума — это точка, где производная меняет знак с минуса на плюс (график $$f'(x)$$ пересекает ось $$Ox$$ снизу вверх).

На графике видим, что это происходит в точке $$x = 1$$.

**Ответ:** $$1$$

---

### Задача 5.2 (ФИПИ — максимум)

**Условие:** На рисунке изображён график производной $$y = f'(x)$$. Найдите точку максимума функции $$f(x)$$ на отрезке $$[-3; 5]$$.

**Решение:**

Точка максимума — это точка, где производная меняет знак с плюса на минус (график $$f'(x)$$ пересекает ось $$Ox$$ сверху вниз).

На графике видим, что это происходит в точке $$x = 2$$.

**Ответ:** $$2$$

## Прототип 6: Найти наибольшее/наименьшее значение производной по графику

### Задача 6.1 (ФИПИ)

**Условие:** На рисунке изображён график производной $$y = f'(x)$$. Найдите наибольшее значение производной на отрезке $$[-2; 4]$$.

**Решение:**

Наибольшее значение производной — это максимальное значение функции $$f'(x)$$ на графике.

На графике видим, что максимум $$f'(x) = 3$$.

**Ответ:** $$3$$

### Задача 6.2 (ФИПИ — наименьшее)

**Решение:**

Наименьшее значение производной — это минимальное значение функции $$f'(x)$$ на графике.

## Прототип 7: Найти количество точек, где касательная параллельна прямой

### Задача 7.1 (ФИПИ)

**Условие:** На рисунке изображён график функции $$y = f(x)$$. Найдите количество точек, в которых касательная к графику функции параллельна прямой $$y = 2x + 5$$.

**Решение:**

Касательная параллельна прямой $$y = 2x + 5$$, если их угловые коэффициенты равны.

Угловой коэффициент прямой: $$k = 2$$.

Значит, нужно найти количество точек, где $$f'(x) = 2$$.

На графике функции проводим горизонтальную линию на уровне $$y = 2$$ и считаем, сколько раз касательная имеет такой наклон.

Если на графике производной (если бы он был дан) мы провели бы горизонтальную линию $$y = 2$$, то количество пересечений — это ответ.

Предположим, что на графике функции таких точек $$3$$.

**Ответ:** $$3$$

## Прототип 8: Определить знак производной в точке по графику функции

### Задача 8.1 (ФИПИ)

**Условие:** На рисунке изображён график функции $$y = f(x)$$. Определите знак производной в точке $$x_0 = 3$$.

**Решение:**

Если функция возрастает в точке $$x_0$$, то $$f'(x_0) > 0$$ (производная положительна).

Если функция убывает в точке $$x_0$$, то $$f'(x_0) < 0$$ (производная отрицательна).

На графике видим, что в точке $$x_0 = 3$$ функция возрастает.

**Ответ:** $$f'(3) > 0$$ (положительна)

## Ловушки и частые ошибки

1. **Путают график функции и график производной** (если дан график $$f'(x)$$, нужно анализировать его, а не $$f(x)$$)
2. **Неправильно определяют точки экстремума** (это точки, где производная меняет знак, а не просто равна нулю)
3. **Забывают, что функция возрастает, когда $$f'(x) > 0$$, а убывает, когда $$f'(x) < 0$$**
4. **Путают точки максимума и минимума** (максимум — производная меняет знак с + на -, минимум — с - на +)
5. **Неправильно считают угловой коэффициент касательной** (забывают учесть масштаб осей)
6. **При определении промежутков возрастания/убывания не учитывают границы отрезка**
7. **Путают наибольшее значение функции и наибольшее значение производной**
