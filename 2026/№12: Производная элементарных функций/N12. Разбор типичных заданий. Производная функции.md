## Прототип 1: Найти точку максимума/минимума функции

### Задача 1.1 (ФИПИ)

**Условие:** Найдите точку максимума функции $$y = x^3 - 3x^2 + 2$$.

**Решение:**

1. Находим производную:

$$y' = 3x^2 - 6x = 3x(x - 2)$$

2. Приравниваем к нулю:

$$3x(x - 2) = 0 \Rightarrow x = 0 \text{ или } x = 2$$

3. Определяем знак производной:

| Интервал | $$(-\infty; 0)$$ | $$(0; 2)$$ | $$(2; +\infty)$$ |
|:---|:---:|:---:|:---:|
| Знак $$y'$$ | $$+$$ | $$-$$ | $$+$$ |
| Поведение $$y$$ | ↗ | ↘ | ↗ |

Точка максимума: $$x = 0$$ (производная меняет знак с + на -).

**Ответ:** $$0$$

---

### Задача 1.2 (ФИПИ)

**Условие:** Найдите точку минимума функции $$y = x^3 - 12x + 5$$.

**Решение:**

$$y' = 3x^2 - 12 = 3(x^2 - 4) = 3(x - 2)(x + 2)$$

$$y' = 0 \Rightarrow x = \pm 2$$

| Интервал | $$(-\infty; -2)$$ | $$(-2; 2)$$ | $$(2; +\infty)$$ |
|:---|:---:|:---:|:---:|
| Знак $$y'$$ | $$+$$ | $$-$$ | $$+$$ |

Точка минимума: $$x = 2$$ (производная меняет знак с - на +).

**Ответ:** $$2$$

## Прототип 2: Найти наибольшее/наименьшее значение функции на отрезке

### Задача 2.1 (ФИПИ)

**Условие:** Найдите наибольшее значение функции $$y = x^3 - 3x + 4$$ на отрезке $$[-2; 2]$$.

**Решение:**

1. Находим производную:

$$y' = 3x^2 - 3 = 3(x^2 - 1) = 3(x - 1)(x + 1)$$

2. Находим критические точки:

$$y' = 0 \Rightarrow x = \pm 1$$

Обе точки принадлежат отрезку $$[-2; 2]$$.

3. Вычисляем значения функции в критических точках и на концах отрезка:

$$y(-2) = -8 + 6 + 4 = 2$$

$$y(-1) = -1 + 3 + 4 = 6$$

$$y(1) = 1 - 3 + 4 = 2$$

$$y(2) = 8 - 6 + 4 = 6$$

Наибольшее значение: $$6$$.

**Ответ:** $$6$$

---

### Задача 2.2 (ФИПИ)

**Условие:** Найдите наименьшее значение функции $$y = x^2 - 4x + 5$$ на отрезке $$[0; 3]$$.

**Решение:**

$$y' = 2x - 4 = 0 \Rightarrow x = 2$$

Точка $$x = 2$$ принадлежит отрезку.

$$y(0) = 5$$

$$y(2) = 4 - 8 + 5 = 1$$

$$y(3) = 9 - 12 + 5 = 2$$

Наименьшее значение: $$1$$.

**Ответ:** $$1$$

## Прототип 3: Найти точку экстремума с показательной функцией

### Задача 3.1 (ФИПИ)

**Условие:** Найдите точку максимума функции $$y = (x - 3)e^{x - 4}$$.

**Решение:**

Используем правило произведения:

$$y' = (x - 3)' \cdot e^{x - 4} + (x - 3) \cdot (e^{x - 4})' = 1 \cdot e^{x - 4} + (x - 3) \cdot e^{x - 4} = e^{x - 4}(1 + x - 3) = e^{x - 4}(x - 2)$$

$$y' = 0 \Rightarrow x - 2 = 0 \Rightarrow x = 2$$ (так как $$e^{x - 4} > 0$$ всегда)

Проверяем знак производной:

- При $$x < 2$$: $$y' < 0$$ (функция убывает)
- При $$x > 2$$: $$y' > 0$$ (функция возрастает)

Точка минимума: $$x = 2$$.

Но в условии спрашивают точку максимума. Проверим ещё раз:

При $$x < 2$$: $$x - 2 < 0$$, $$e^{x - 4} > 0$$, значит $$y' < 0$$.

При $$x > 2$$: $$x - 2 > 0$$, $$e^{x - 4} > 0$$, значит $$y' > 0$$.

Это точка минимума. Если в условии была другая функция, например $$y = (3 - x)e^{x - 4}$$, то:

$$y' = -(e^{x - 4}) + (3 - x)e^{x - 4} = e^{x - 4}(3 - x - 1) = e^{x - 4}(2 - x)$$

$$y' = 0 \Rightarrow x = 2$$

При $$x < 2$$: $$y' > 0$$, при $$x > 2$$: $$y' < 0$$ — точка максимума.

**Ответ:** $$2$$ (для функции $$y = (3 - x)e^{x - 4}$$)

## Прототип 4: Найти точку экстремума с логарифмом

### Задача 4.1 (ФИПИ)

**Условие:** Найдите точку минимума функции $$y = x \ln x - x$$.

**Решение:**

$$y' = (\ln x + x \cdot \frac{1}{x}) - 1 = \ln x + 1 - 1 = \ln x$$

$$y' = 0 \Rightarrow \ln x = 0 \Rightarrow x = 1$$

Проверяем знак:

- При $$0 < x < 1$$: $$\ln x < 0$$, $$y' < 0$$ (убывает)
- При $$x > 1$$: $$\ln x > 0$$, $$y' > 0$$ (возрастает)

Точка минимума: $$x = 1$$.

**Ответ:** $$1$$

## Прототип 5: Найти точку экстремума дробно-рациональной функции

### Задача 5.1 (ФИПИ)

**Условие:** Найдите точку максимума функции $$y = \frac{x^2 + 4}{x}$$.

**Решение:**

$$y = x + \frac{4}{x}$$

$$y' = 1 - \frac{4}{x^2}$$

$$y' = 0 \Rightarrow 1 - \frac{4}{x^2} = 0 \Rightarrow x^2 = 4 \Rightarrow x = \pm 2$$

Проверяем знак для $$x > 0$$ (так как функция определена при $$x \neq 0$$):

- При $$0 < x < 2$$: $$x^2 < 4$$, $$\frac{4}{x^2} > 1$$, $$y' < 0$$ (убывает)
- При $$x > 2$$: $$x^2 > 4$$, $$\frac{4}{x^2} < 1$$, $$y' > 0$$ (возрастает)

Точка минимума для $$x > 0$$: $$x = 2$$.

Для $$x < 0$$:

- При $$x < -2$$: $$y' > 0$$ (возрастает)
- При $$-2 < x < 0$$: $$y' < 0$$ (убывает)

Точка максимума для $$x < 0$$: $$x = -2$$.

**Ответ:** $$-2$$ (если ищем максимум на всей области определения)

## Прототип 6: Найти количество точек экстремума

### Задача 6.1 (ФИПИ)

**Условие:** Найдите количество точек экстремума функции $$y = x^4 - 8x^2 + 5$$.

**Решение:**

$$y' = 4x^3 - 16x = 4x(x^2 - 4) = 4x(x - 2)(x + 2)$$

$$y' = 0 \Rightarrow x = 0, \pm 2$$

Проверяем знак:

| Интервал | $$(-\infty; -2)$$ | $$(-2; 0)$$ | $$(0; 2)$$ | $$(2; +\infty)$$ |
|:---|:---:|:---:|:---:|:---:|
| Знак $$y'$$ | $$-$$ | $$+$$ | $$-$$ | $$+$$ |

Производная меняет знак в каждой из трёх точек, значит все три точки — точки экстремума.

**Ответ:** $$3$$

## Прототип 7: Найти наибольшее значение производной

### Задача 7.1 (ФИПИ)

**Условие:** Найдите наибольшее значение функции $$y = 3x - x^3$$ на отрезке $$[-2; 2]$$.

**Решение:**

$$y' = 3 - 3x^2 = 3(1 - x^2) = 3(1 - x)(1 + x)$$

$$y' = 0 \Rightarrow x = \pm 1$$

$$y(-2) = -6 - (-8) = 2$$

$$y(-1) = -3 - (-1) = -2$$

$$y(1) = 3 - 1 = 2$$

$$y(2) = 6 - 8 = -2$$

Наибольшее значение: $$2$$.

**Ответ:** $$2$$

## Ловушки и частые ошибки

1. **Путают точку экстремума и значение функции в этой точке**
2. **Забывают проверить, принадлежат ли критические точки заданному отрезку**
3. **При нахождении наибольшего/наименьшего значения забывают проверить концы отрезка**
4. **Неправильно определяют знак производной** (забывают, что максимум — это смена знака с + на -, минимум — с - на +)
5. **При дифференцировании произведения или частного неправильно применяют правила**
6. **Забывают, что $$e^x > 0$$ всегда, поэтому при решении $$e^x \cdot f(x) = 0$$ достаточно решить $$f(x) = 0$$**
7. **Путают производную функции и саму функцию**
8. **Неправильно вычисляют производную сложной функции** (забывают умножить на производную внутренней функции)
