## 1. База

### Определение

$$\log_a b = c \iff a^c = b$$

Читается: **«в какую степень возвести $a$, чтобы получить $b$»**.

Примеры: $\log_2 8 = 3$ (т.к. $2^3 = 8$); $\log_5 \dfrac{1}{25} = -2$ (т.к. $5^{-2} = \dfrac{1}{25}$); $\log_7 1 = 0$.

### Три ограничения (это и есть ОДЗ)

$$a > 0,\qquad a \ne 1,\qquad b > 0$$

Основание - положительное и не единица, под логарифмом - строго положительное. **Любая задача с логарифмом начинается с этих трёх строк.**

### Основное логарифмическое тождество

$$a^{\log_a b} = b$$

Обозначения: $\lg x = \log_{10} x$ (десятичный), $\ln x = \log_e x$ (натуральный).

### Свойства (все - при допустимых значениях)

| № | Свойство | Мини-пример |
|:---:|---|---|
| 1 | $\log_a 1 = 0,\quad \log_a a = 1$ | $\log_9 9 = 1$ |
| 2 | $\log_a (bc) = \log_a b + \log_a c$ | $\log_6 4 + \log_6 9 = \log_6 36 = 2$ |
| 3 | $\log_a \dfrac{b}{c} = \log_a b - \log_a c$ | $\log_2 48 - \log_2 3 = \log_2 16 = 4$ |
| 4 | $\log_a b^k = k \log_a b$ (при $b>0$) | $\log_3 81 = \log_3 3^4 = 4$ |
| 5 | $\log_{a^m} b = \dfrac{1}{m} \log_a b$ | $\log_{25} 49 = \dfrac{1}{2}\log_5 49 = \log_5 7$ |
| 6 | Переход к новому основанию: $\log_a b = \dfrac{\log_c b}{\log_c a}$ | $\dfrac{\log_5 64}{\log_5 4} = \log_4 64 = 3$ |
| 7 | Следствие из 6: $\log_a b = \dfrac{1}{\log_b a}$ | $\log_2 3 \cdot \log_3 2 = 1$ |

## 2. Выражения (№ 8). Алгоритм

1. **Одно основание.** Приведи все логарифмы к общему основанию (свойства 5–6).
2. **Свойства в нужную сторону.** Сумму/разность логарифмов сворачивай в один (свойства 2–3) или, наоборот, разбирай.
3. **Ищи степени.** Представляй числа как степени общего основания: $8 = 2^3$, $0{,}2 = 5^{-1}$, $\sqrt{3} = 3^{1/2}$.

**Разобранные примеры.**

**а)** $\lg 8 + \lg 12{,}5 = \lg(8 \cdot 12{,}5) = \lg 100 = 2$.

**б)** $5^{\log_{25} 49} = 5^{\frac{1}{2}\log_5 49} = 5^{\log_5 7} = 7$ - сначала свойство 5, потом тождество.

**в)** $36^{\log_6 5} = \left(6^2\right)^{\log_6 5} = \left(6^{\log_6 5}\right)^2 = 5^2 = 25$.

## 3. Простейшие уравнения (№ 7). Алгоритм

$$\log_a f(x) = b \quad\Longrightarrow\quad f(x) = a^b$$

1. Переведи логарифм в степень по определению.
2. Реши получившееся уравнение.
3. **Проверь подстановкой**: аргумент должен получиться положительным, основание (если в нём была переменная) - положительным и не равным 1.

**Разобранные примеры.**

**а)** $\log_2(4 - x) = 7 \Rightarrow 4 - x = 2^7 = 128 \Rightarrow x = -124$.
Проверка: $4 - (-124) = 128 > 0$. ✔ Ответ: $-124$.

**б)** $\log_{x+1} 27 = 3 \Rightarrow (x+1)^3 = 27 \Rightarrow x + 1 = 3 \Rightarrow x = 2$.
Проверка основания: $x + 1 = 3 > 0,\ \ne 1$. ✔ Ответ: $2$.

## 4. Уравнения части 2 (№ 14). Два главных приёма

**Алгоритм:** ОДЗ → одно основание → замена → решить → вернуться к $x$ → отбросить посторонние корни по ОДЗ.

### Приём 1: замена $t = \log_a x$

Если уравнение - «квадратное относительно логарифма», заменяй.

$$(\log_3 x)^2 - 4\log_3 x + 3 = 0$$

ОДЗ: $x > 0$. Замена $t = \log_3 x$: $\;t^2 - 4t + 3 = 0 \Rightarrow t = 1$ или $t = 3$.
Возврат: $\log_3 x = 1 \Rightarrow x = 3$; $\log_3 x = 3 \Rightarrow x = 27$. Оба в ОДЗ. **Ответ: $3;\ 27$.**

### Приём 2: перевернуть логарифм (свойство 7)

$$\log_4 x + \log_x 4 = \frac{5}{2}$$

ОДЗ: $x > 0$, $x \ne 1$. Так как $\log_x 4 = \dfrac{1}{\log_4 x}$, замена $t = \log_4 x$:

$$t + \frac{1}{t} = \frac{5}{2} \;\Rightarrow\; 2t^2 - 5t + 2 = 0 \;\Rightarrow\; t = 2 \text{ или } t = \frac{1}{2}$$

Возврат: $x = 4^2 = 16$ или $x = 4^{1/2} = 2$. Оба в ОДЗ. **Ответ: $2;\ 16$.**
Проверка: $\log_4 16 + \log_{16} 4 = 2 + \tfrac{1}{2}$ ✔; $\log_4 2 + \log_2 4 = \tfrac{1}{2} + 2$ ✔.

## 5. Неравенства (№ 16). Монотонность и рационализация

### Инструмент 1: монотонность (основание - число)

$$\log_a f(x) > \log_a g(x)$$

- если $a > 1$: знак **сохраняется** → $f(x) > g(x)$;
- если $0 < a < 1$: знак **переворачивается** → $f(x) < g(x)$;
- и в обоих случаях - ОДЗ: $f(x) > 0$, $g(x) > 0$.

**Пример.** $\log_{1/2}(x - 3) \ge -2$.
ОДЗ: $x > 3$. Представим $-2 = \log_{1/2} 4$. Основание меньше 1 - знак переворачивается:
$$x - 3 \le 4 \Rightarrow x \le 7$$
С ОДЗ: **$x \in (3;\ 7\,]$**.

### Инструмент 2: метод рационализации (основание с переменной)

На ОДЗ знак выражения слева совпадает со знаком выражения справа:

| Было | Заменяем на |
|---|---|
| $\log_a f - \log_a g$ | $(a - 1)(f - g)$ |
| $\log_a f$ | $(a - 1)(f - 1)$ |

ОДЗ выписывается отдельно и обязательно: $f > 0$, $g > 0$, $a > 0$, $a \ne 1$.

**Алгоритм:** ОДЗ отдельно → привести к разности логарифмов с одним основанием → рационализация → метод интервалов → пересечь с ОДЗ.

**Пример.** $\log_x(3 - x) \le 1$.

ОДЗ: $x > 0$, $x \ne 1$, $3 - x > 0$, то есть $x \in (0; 1) \cup (1; 3)$.

Приводим к разности: $\log_x(3-x) - \log_x x \le 0$. Рационализация:
$$(x - 1)\big((3 - x) - x\big) \le 0 \;\Longrightarrow\; (x-1)(3 - 2x) \le 0$$

Корни $1$ и $1{,}5$; старший коэффициент отрицательный, поэтому решение - вне корней: $x \le 1$ или $x \ge 1{,}5$.

Пересекаем с ОДЗ: **$x \in (0; 1) \cup [\,1{,}5;\ 3)$**.
Контроль граничной точки: при $x = 1{,}5$: $\log_{1{,}5} 1{,}5 = 1 \le 1$ ✔.

## 6. Ловушки - где теряют баллы

1. $\log_a(b + c) \ne \log_a b + \log_a c$. Свойство - про **произведение**, суммы логарифм не раскладывает.
2. **ОДЗ выписывается до преобразований.** Свойства 2–4 могут расширить область определения - и подарить посторонний корень.
3. Основание меньше единицы → знак неравенства **переворачивается**. Основание с переменной → рационализация (или два случая), а не «как с числом».
4. $\log_a b^2 = 2\log_a b$ - только при $b > 0$. В общем случае $\log_a b^2 = 2\log_a |b|$.
5. После замены $t = \log_a x$ ответ - это $x$, а не $t$. Вернись к переменной.
6. Корни уравнения проверяй подстановкой в **исходное** уравнение, а не в преобразованное.
