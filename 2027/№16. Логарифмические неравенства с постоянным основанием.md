# № 16. Логарифмические неравенства с постоянным основанием

Конспект для ученика — по реальным задачам банка ФИПИ. Задание № 16 (часть 2, 2 первичных балла; в папке `2026/` этот тип лежит под № 15). Хитрых идей здесь нет — есть четыре повторяющихся типа и дисциплина из пяти шагов.

---

## 1. Опорные факты

**Монотонность** — то, на чём держится снятие логарифма:

| Основание | Функция $y = \log_a x$ | При снятии логарифма знак |
|:---:|:---:|:---:|
| $a > 1$ | возрастает | **сохраняется** |
| $0 < a < 1$ | убывает | **переворачивается** |

Фраза-обоснование для чистовика: *«Так как основание ... больше 1, функция возрастает, поэтому неравенство равносильно...»* — эксперт должен видеть, что переход обоснован.

**Приёмы, которые встречаются в каждой второй задаче ФИПИ:**

- Число упаковывается в логарифм: $c = \log_a a^c$; и наоборот: $\log_2 32x = 5 + \log_2 x$, $\log_4 64x = 3 + \log_4 x$.
- Смена основания-степени: $\log_{a^m} b = \tfrac{1}{m}\log_a b$. Например, $\log_{0{,}25} A = \tfrac{1}{2}\log_{0{,}5} A$, $\log_{16} A = \tfrac{1}{4}\log_2 A$.
- **Чётная степень под логарифмом — это модуль:** $\log_a x^{2k} = 2k\log_a |x|$. Если ОДЗ уже дало $x > 0$ (так бывает в задачах с $\log_a x$ в знаменателях) — модуль снимается: $\log_4 x^4 = 4\log_4 x$. Если нет — модуль обязателен.
- Узнавание скрытых степеней: $x^3 - 3x^2 + 3x - 1 = (x-1)^3$, $x^2 + 10x + 25 = (x+5)^2$, $x^3 - 3x^2 - 9x + 27 = (x-3)^2(x+3)$ — ФИПИ любит прятать куб и квадрат в развёрнутом виде.
- Квадратный трёхчлен с отрицательным дискриминантом положителен при всех $x$ — это пишется одной строкой и позволяет законно умножать на него обе части.

## 2. Алгоритм и карта типов

**Алгоритм — всегда один:**

1. **ОДЗ письменно, до преобразований**: каждый аргумент $> 0$, знаменатели $\ne 0$.
2. **Собрать логарифмы**: суммы и разности — в один логарифм, числа — упаковать.
3. Если в неравенстве $\log^2$ или дроби из логарифмов — **замена** $t = \log_a x$ (или $t = \log_a(\text{блок})$).
4. **Снять логарифм с обоснованием** через монотонность; дроби — только переносом в одну сторону, **на знаменатель не умножать**.
5. **Метод интервалов → пересечь с ОДЗ → ответ промежутками.**

**Карта типов банка ФИПИ** — как узнать задачу в лицо:

| Тип | Как выглядит | Что делать |
|---|---|---|
| **А. Квадрат по блоку** | $\log_a^2(\ldots) + p\log_a(\ldots) + q \ge 0$, внутри блок вида $25 - x^2$ | Замена $t = \log_a(\text{блок})$, квадратное по $t$, возврат — два двойных неравенства по $x$ |
| **Б. Сумма/разность логарифмов** | Несколько логарифмов с одним основанием, внутри дроби и многочлены | Собрать в один логарифм с каждой стороны, сравнить аргументы, дробно-рациональное неравенство |
| **В. Дроби из $\log_a x$** | Этажи вида $\dfrac{\log_a (a^k x)}{\log_a x - m}$, часто симметричные | Замена $t = \log_a x$, общий знаменатель; в числителе обычно сворачивается $(t - c)^2$ |
| **Г. Скрытые степени** | Кубы и чётные степени: $\log_{0{,}5}(x^3 - 3x^2 - 9x + 27)$, $\log_{0{,}25}(x-3)^4$, основание $(x+5)^2$ | Узнать степень, выровнять основания через $\log_{a^m}$, чётную степень — через модуль |

## 3. Разобранные примеры (задачи ФИПИ)

### Тип А. Замена по блоку

$$\log_3^2\left(x^2 - 16\right) - 5\log_3\left(x^2 - 16\right) + 6 \ge 0$$

ОДЗ: $x^2 - 16 > 0$.

Замена $t = \log_3(x^2 - 16)$: $\;t^2 - 5t + 6 \ge 0 \Rightarrow (t-2)(t-3) \ge 0 \Rightarrow t \le 2$ или $t \ge 3$.

Обратная замена — ОДЗ уже встроено в левые части двойных неравенств:
$$t \le 2:\; 0 < x^2 - 16 \le 9 \;\Rightarrow\; 16 < x^2 \le 25 \;\Rightarrow\; x \in [-5; -4) \cup (4; 5]$$
$$t \ge 3:\; x^2 - 16 \ge 27 \;\Rightarrow\; x^2 \ge 43 \;\Rightarrow\; x \in \left(-\infty; -\sqrt{43}\,\right] \cup \left[\sqrt{43}; +\infty\right)$$

**Ответ:** $x \in \left(-\infty; -\sqrt{43}\,\right] \cup [-5; -4) \cup (4; 5] \cup \left[\sqrt{43}; +\infty\right)$.

*Контроль:* границы $x = \pm 4$ выколоты (аргумент 0), $x = \pm 5$ включены ($t = 2$), $\sqrt{43} \approx 6{,}6$ — промежутки не слиплись.

### Тип Б. Собрать и сравнить аргументы

$$\log_7\left(2x^2 + 12\right) - \log_7\left(x^2 - x + 12\right) \ge \log_7\left(2 - \frac{1}{x}\right)$$

У трёхчлена $x^2 - x + 12$ дискриминант $D = 1 - 48 < 0$, значит он положителен при всех $x$ — его логарифм определён всегда. ОДЗ: $2 - \tfrac{1}{x} > 0 \Rightarrow \tfrac{2x-1}{x} > 0 \Rightarrow x < 0$ или $x > \tfrac{1}{2}$.

Слева — один логарифм: $\log_7 \dfrac{2x^2+12}{x^2-x+12} \ge \log_7 \dfrac{2x-1}{x}$. Основание $7 > 1$, знак сохраняется; умножение на $x^2 - x + 12 > 0$ законно:

$$\frac{\left(2x^2+12\right)x - (2x-1)\left(x^2-x+12\right)}{x} \ge 0 \;\Rightarrow\; \frac{3x^2 - 13x + 12}{x} \ge 0 \;\Rightarrow\; \frac{(3x-4)(x-3)}{x} \ge 0$$

Метод интервалов (нули $\tfrac{4}{3}$, $3$; полюс $0$): решение $\left(0; \tfrac{4}{3}\right] \cup [3; +\infty)$. Пересекаем с ОДЗ:

**Ответ:** $x \in \left(\tfrac{1}{2}; \tfrac{4}{3}\right] \cup [3; +\infty)$.

### Тип В. Дроби из $\log_a x$ и изолированная точка

$$\frac{\log_4 64x}{\log_4 x - 3} + \frac{\log_4 x - 3}{\log_4 64x} \ge \frac{\log_4 x^4 + 16}{\log_4^2 x - 9}$$

Из области определения $\log_4 x$ следует $x > 0$, поэтому $\log_4 x^4 = 4\log_4 |x| = 4\log_4 x$, а $\log_4 64x = \log_4 x + 3$. Замена $t = \log_4 x$:

$$\frac{t+3}{t-3} + \frac{t-3}{t+3} \ge \frac{4t+16}{(t-3)(t+3)} \;\Rightarrow\; \frac{(t+3)^2 + (t-3)^2 - 4t - 16}{(t-3)(t+3)} \ge 0 \;\Rightarrow\; \frac{2(t-1)^2}{(t-3)(t+3)} \ge 0$$

Числитель — полный квадрат: он не меняет знак, но его ноль $t = 1$ — **отдельная точка решения**. Метод интервалов: $t < -3$, $t > 3$ и точка $t = 1$.

Обратная замена: $x < 4^{-3}$, $x > 4^3$, $x = 4$ — и всё при $x > 0$.

**Ответ:** $x \in \left(0; \tfrac{1}{64}\right) \cup \{4\} \cup (64; +\infty)$.

*Изолированная точка $\{4\}$ — фирменный знак этого типа: потерять её — потерять балл.*

### Тип Г. Скрытые степени и модуль

$$\log_{0{,}5}\left(x^3 - 3x^2 - 9x + 27\right) \le \log_{0{,}25}(x-3)^4$$

Справа выравниваем основание и снимаем чётную степень через модуль:
$$\log_{0{,}25}(x-3)^4 = \tfrac{1}{2}\log_{0{,}5}(x-3)^4 = 2\log_{0{,}5}|x-3| = \log_{0{,}5}(x-3)^2$$

Слева узнаём разложение: $x^3 - 3x^2 - 9x + 27 = (x-3)^2(x+3)$.

ОДЗ: $(x-3)^2(x+3) > 0$ и $(x-3)^4 > 0$, то есть $x > -3$, $x \ne 3$.

Основание $0{,}5 < 1$ — знак переворачивается:
$$(x-3)^2(x+3) \ge (x-3)^2 \;\Rightarrow\; (x-3)^2\big((x+3) - 1\big) \ge 0 \;\Rightarrow\; (x-3)^2(x+2) \ge 0$$

Множитель $(x-3)^2 \ge 0$ всегда, поэтому неравенство равносильно $x \ge -2$ (точка $x = 3$ и так выколота ОДЗ).

**Ответ:** $x \in [-2; 3) \cup (3; +\infty)$.

## 4. Где теряют балл — семь граблей

1. **ОДЗ после преобразований** или устно. ОДЗ — первое действие, письменно.
2. **Непереворот знака** при основании меньше 1 (тип Г).
3. **Умножение на знаменатель** с неизвестным знаком. Только перенос в одну сторону. Исключение — множитель, положительность которого доказана (трёхчлен с $D < 0$), и это доказательство написано.
4. **Потерянная изолированная точка** из квадрата в числителе: $(t-1)^2$ даёт $\{4\}$ в ответе (тип В).
5. **Сокращение на $(x-3)^2$** без учёта его нуля. Квадрат не сокращают — выносят и разбирают его ноль отдельно.
6. **Чётная степень без модуля**: $\log_a x^4 = 4\log_a x$ верно только при $x > 0$; сначала показать, откуда $x > 0$, потом снимать модуль.
7. **Возврат от $t$ к $x$ без встроенного ОДЗ**: $t \le 2$ означает $0 < x^2 - 16 \le 9$, а не просто $x^2 - 16 \le 9$.

## 5. Тренировка (все задачи — из банка ФИПИ)

Ответы в конце листа, полные решения всех задач — в подборке-решебнике. Решать с полным оформлением, как на экзамене.

1. $2^{\log_2(\log_2 x)} + \log_4^2 x - 3 \le 0$
2. $\log_3^2\left(25 - x^2\right) - 3\log_3\left(25 - x^2\right) + 2 \ge 0$
3. $\log_2^2\left(x^2 - 9\right) - 9\log_2\left(x^2 - 9\right) + 20 \ge 0$
4. $\log_3\big((2-x)(x^2+5)\big) \ge \log_3\left(x^2 - 5x + 6\right) + \log_3(4 - x)$
5. $\log_2\left(4x^2 - 1\right) - \log_2 x \le \log_2\left(5x + \dfrac{9}{x} - 11\right)$
6. $\dfrac{\log_4\left(16x^4\right) + 11}{\log_4^2 x - 9} \ge -1$
7. $1 + \dfrac{5}{\log_4 x - 3} + \dfrac{6}{\log_4^2 x - \log_4\left(64x^6\right) + 12} \ge 0$
8. $\log_{16}(x + 5) + \log_{x^2 + 10x + 25} 2 \ge \dfrac{3}{4}$

---

## Ответы

1. $x \in (1;\ 4]$ — ловушка на входе: $2^{\log_2(\log_2 x)} = \log_2 x$, но это требует $\log_2 x > 0$, то есть $x > 1$.
2. $x \in \left(-5; -\sqrt{22}\,\right] \cup [-4; 4] \cup \left[\sqrt{22}; 5\right)$ — тип А: $t \le 1$ или $t \ge 2$.
3. $x \in \left(-\infty; -\sqrt{41}\,\right] \cup [-5; -3) \cup (3; 5] \cup \left[\sqrt{41}; +\infty\right)$ — тип А: $t \le 4$ или $t \ge 5$.
4. $x \in [1;\ 2)$ — тип Б: вынести $(2 - x)$, внутри скобки остаётся $7x - 7$.
5. $x \in \left(\tfrac{1}{2};\ 1\right] \cup [10; +\infty)$ — тип Б: после умножения на $x > 0$ остаётся $(x-1)(x-10) \ge 0$.
6. $x \in \left(0; \tfrac{1}{64}\right) \cup \left\{\tfrac{1}{16}\right\} \cup (64; +\infty)$ — тип В: $\dfrac{(t+2)^2}{(t-3)(t+3)} \ge 0$; не потеряй точку $t = -2$.
7. $x \in (0;\ 1] \cup [4;\ 64) \cup (64; +\infty)$ — тип В: знаменатель сворачивается в $(t-3)^2$, точка $x = 64$ выколота.
8. $x \in (-4; -3] \cup [-1; +\infty)$ — тип Г: $x^2 + 10x + 25 = (x+5)^2$, далее $\log_{(x+5)^2} 2 = \dfrac{1}{2\log_2(x+5)}$ при $x + 5 > 0$.
